# Hospitality Dashboard | Power BI Project

## Overview
This Power BI dashboard provides comprehensive insights into hospitality business performance including revenue trends, occupancy analysis, booking behavior, customer ratings, and hotel category performance.

The dashboard helps stakeholders monitor KPIs, identify revenue opportunities, reduce cancellations, and improve operational efficiency.

# Key KPIs

- Total Bookings: 135K
- Total Revenue: 2 Billion
- Occupancy Rate: 57.87%
- ADR (Average Daily Rate): 12.70K
- RevPAR: 7.35K
- Average Rating: 3.62
- Cancellation Rate: 24.83%

---

# Business Insights

- Mumbai generates the highest revenue among all cities.
- Weekend revenue is significantly higher than weekday revenue.
- Elite hotels contribute the highest revenue share.
- Cancellation rate is high and impacts realized revenue.
- Occupancy fluctuates despite relatively stable revenue trends.
